CampusPQ

AI-driven learning backend for students, tutors, and administrators.

The Problem

AI learning platforms need to handle many concurrent requests and stream data back to users quickly. A traditional monolithic backend struggles to do this efficiently once usage grows beyond a handful of users.

The Solution

I architected and built the CampusPQ backend on Python and FastAPI, designed to handle asynchronous AI inference requests while keeping a lightweight footprint, so response times stay fast as more students and tutors use the platform at once.
